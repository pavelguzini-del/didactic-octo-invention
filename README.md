# Alice ChatGPT — сборка 67

## Файлы
- `app.py` — webhook Алисы и запросы к OpenAI Responses API.
- `requirements.txt` — зависимости.
- `render.yaml` — конфигурация Render.
- `.gitignore` — исключает секреты и временные файлы.
- `.env.example` — пример переменных окружения без настоящего ключа.

## Важно
- По умолчанию используется `gpt-4.1-mini`. Модель должна быть доступна вашему OpenAI API-проекту.
- OpenAI API оплачивается отдельно от подписки ChatGPT.
- Не помещайте API-ключ в код или GitHub. Добавьте его в Render → Environment как `OPENAI_API_KEY`.
- Время ожидания OpenAI ограничено примерно 3,7 секунды, чтобы оставить время на ответ Алисе. Медленный ответ модели или сети всё равно может привести к тайм-ауту.
- Бесплатный хостинг, который засыпает после простоя, может задерживать первый запрос.
- Алиса распознаёт речь, сервер передаёт текст в OpenAI, а Алиса озвучивает ответ. Прямой обмен аудио не используется.

## Развёртывание на Render
1. Распакуйте архив.
2. Создайте приватный репозиторий GitHub `alice-chatgpt`.
3. Загрузите в корень репозитория все файлы из архива.
4. В Render выберите New → Blueprint и подключите репозиторий (или создайте Web Service вручную).
5. Для ручной настройки:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn --workers 1 --threads 4 --timeout 30 app:app`
6. В Render → Environment добавьте:
   - `OPENAI_API_KEY` = ваш секретный ключ
   - `OPENAI_MODEL` = `gpt-4.1-mini`
7. Выполните Deploy и дождитесь статуса Live.
8. Проверьте корневой адрес сервиса: должен отображаться `Alice ChatGPT webhook is running.`
9. В Яндекс Диалогах укажите webhook URL с окончанием `/alice`.

## Проверка
В тестере отправьте короткий вопрос. Если ответ не приходит, откройте Render → Logs:
- `OpenAI API request timed out` — модель/сеть не успела ответить.
- HTTP 401 — проверьте API-ключ.
- HTTP 429 — проверьте лимиты и биллинг API.
- `model_not_found` — выберите модель, доступную вашему API-проекту.

## Локальный запуск
Нужен Python 3.10+:
1. `pip install -r requirements.txt`
2. Установите переменные окружения `OPENAI_API_KEY` и `OPENAI_MODEL`.
3. Запустите `python app.py`.
